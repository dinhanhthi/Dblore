Dblore

A clean, native macOS client for your databases. Notebooks and a SQL editor in one tidy workspace, with shortcuts for everything you run.

Download GitHub

macOS 14+ · Apple Silicon · Free & open source (AGPLv3)

Main features

  • Notebooks and SQL editor: .dblore notebooks with inline results, plain .sql tabs and quick Markdown notes, in one tidy workspace. Autocomplete knows CTEs and ORDER BY aliases, Format SQL follows your rules, and View > Zoom resizes the editor, grid or diagram.
  • Schema browser: tables, columns and types, a quick filter, a canvas with foreign-key lines, a Temporary section for the session's temp tables, and attached SQLite databases.
  • Join query builder: pick tables and get the join along their foreign keys, with columns, filters and a live SQL preview.
  • Structure editor: add, change and drop columns, indexes and keys, with a preview of the exact SQL that runs.
  • Compare Schemas & Sync: compare two PostgreSQL, MySQL/MariaDB or SQLite schemas, review the exact script, and run it through Safe Mode, with drops unticked by default.
  • Results grid: sort, search, filter, edit values inline, add rows from a form, follow foreign keys, inspect cells as JSON, color values by type, pin a result to compare re-runs and freeze leading columns in table tabs. Binary values show as hex, UUID, MessagePack or Protobuf, and cells over 64 KB load only when you open them.
  • Charts: switch any result between grid and chart.
  • Import and export: import CSV, TSV and JSON as new rows or updates matched by key, several files or a folder in one transaction; export to Excel, CSV, JSON, Markdown, PDF, TSV and SQL INSERT.
  • Generate Rows: fill a table with up to 1,000,000 rows of sample data that follow its types, foreign keys and unique keys.
  • SQL dump and restore: dump a PostgreSQL, MySQL/MariaDB or SQLite database to a .sql file and restore it.
  • Safe Mode: confirmation before destructive statements, Commit / Rollback for pending transactions, Touch ID to unlock.
  • Lock: lock a connection, a database file or a whole workspace behind Touch ID, the Mac password or a Lock password. Locked workspaces are encrypted on disk, and locked items relock on sleep, screen lock or idle.
  • Related rows before a delete: see the rows a delete would cascade to, set to NULL or be blocked by, before you commit it.
  • Query Insights: your queries grouped by shape, with runs, average, p95 and slowest time, and error rate.
  • AI assistant: write, explain and fix SQL with your own key or a local model (on-device models need the On-device AI plugin). Nothing runs unless you allow read-only queries, and row values are never sent. It can call tools of outside MCP servers you add, each call only after you press Run once.
  • MCP server: let Claude Code or Cursor read the connections you allow, on this Mac only. Off by default. Optional write tools run one change at a time, only after you approve it.
  • Keyboard-first: run cells and queries without leaving the keys, and find any command with Cmd+K.
  • All features

Databases

  • PostgreSQL: saved connections, passwords in the Keychain, SSL, client certificates, SSH tunnels, read-only mode, and import from DBeaver, TablePlus, DataGrip, .pgpass or a URI.
  • MySQL and MariaDB: TCP or SSH tunnel, TLS and client certificates, staged edits by primary key, foreign-key lookup, CSV import, routine and trigger source, and import from DBeaver, TablePlus, DataGrip or a mysql:// URI.
  • MongoDB: a connection string or form, mongosh commands, a collection screen with a filter bar, schema, indexes and validation, editable document cards, an aggregation builder, index and collection administration, export, import, backup and restore, and edits staged by _id and confirmed in Safe Mode.
  • SQLite: open a file and work with it like a server connection.

Plugins

Optional engines and features, installed from Settings > Plugins: a signed, notarized download, checked before every load and removable at any time.

  • DuckDB: open a .duckdb file or an in-memory database, browse its schema and query Parquet or CSV files.
  • On-device AI: run AI models on this Mac with MLX for the AI chat and inline suggestions. Models download separately, each file checked by its SHA-256.

Get started

  1. Download the signed and notarized DMG from the releases page and drag Dblore to Applications.
  2. Connect to a PostgreSQL, MySQL, MariaDB or MongoDB server, or open a SQLite file.
  3. Create a notebook (Cmd+T) and run a cell (Ctrl+Enter).
