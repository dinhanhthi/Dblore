Dblore

A clean, native macOS client for your databases. Notebooks and a SQL editor in one tidy workspace, with shortcuts for everything you run.

Download GitHub

macOS 14+ · Apple Silicon · Free & open source (AGPLv3)

Main features

  • Notebooks and SQL editor: .dblore notebooks with inline results, plain .sql tabs and quick Markdown notes, in one tidy workspace.
  • Schema browser: tables, columns and types, a quick filter and a canvas with foreign-key lines.
  • Results grid: sort, search, filter, edit values inline, follow foreign keys, inspect cells as JSON and pin a result to compare re-runs.
  • Charts: switch any result between grid and chart.
  • Import and export: import CSV, TSV and JSON; export to Excel, CSV, JSON, Markdown, PDF, TSV and SQL INSERT.
  • Safe Mode: confirmation before destructive statements, Commit / Rollback for pending transactions, Touch ID to unlock.
  • AI assistant: write, explain and fix SQL with your own key or a local model. Generated SQL never runs automatically.
  • Keyboard-first: run cells and queries without leaving the keys, and find any command with Cmd+K.
  • All features

Databases

  • PostgreSQL: saved connections, passwords in the Keychain, SSL, client certificates, SSH tunnels, read-only mode, and import from DBeaver, TablePlus, DataGrip, .pgpass or a URI.
  • SQLite (beta): open a file and work with it like a server connection.

Plugins

Optional engines, installed from Settings > Plugins: a signed, notarized download, checked before every load and removable at any time.

  • DuckDB: open a .duckdb file or an in-memory database, browse its schema and query Parquet or CSV files.

Get started

  1. Download the signed and notarized DMG from the releases page and drag Dblore to Applications.
  2. Connect to a PostgreSQL server or open a SQLite file.
  3. Create a notebook (Cmd+T) and run a cell (Ctrl+Enter).
