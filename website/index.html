Dblore

A clean, native macOS client for your databases. Notebooks and a SQL editor in one tidy workspace, with shortcuts for everything you run.

Download GitHub

macOS 14+ · Apple Silicon · Free & open source (AGPLv3)

Main features

  • Notebooks and SQL editor: inline results, autocomplete and formatting in one tidy workspace.
  • Schema tools: schema browser and canvas, structure editor, join query builder and schema compare.
  • Results grid: sort, filter, edit inline, chart, import and export.
  • Safe Mode and Lock: confirm destructive statements and lock connections behind Touch ID.
  • AI assistant, MCP server and command line: with your own key or a local model.
  • All features, with search

Databases

PostgreSQL, MySQL, MariaDB, MongoDB and SQLite are built in. DuckDB, SQL Server and ClickHouse are plugins. CockroachDB, Redshift, YugabyteDB, TiDB and SingleStore connect as presets. Details per engine are on the features page.

Plugins

DuckDB, SQL Server, ClickHouse and On-device AI: installed from Settings > Plugins, as a signed, notarized download that is checked before every load and removable at any time.

Get started

  1. Download the signed and notarized DMG from the releases page and drag Dblore to Applications.
  2. Connect to a PostgreSQL, MySQL, MariaDB or MongoDB server (or a SQL Server or ClickHouse server once its plugin is installed), or open a SQLite file.
  3. Create a notebook (Cmd+T) and run a cell (Ctrl+Enter).

More in the docs. Dblore updates itself.
