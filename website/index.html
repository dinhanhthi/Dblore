Dblore

A clean, native macOS client for your databases. Notebooks and a SQL editor in one tidy workspace, with shortcuts for everything you run.

Download GitHub

macOS 14+ · Apple Silicon · Free & open source (AGPLv3)

Main features

  • Notebooks and SQL editor: .dblore notebooks with inline results, plain .sql tabs and quick Markdown notes, in one tidy workspace. Autocomplete knows CTEs and ORDER BY aliases, suggests the foreign-key condition after a join's ON and matches names in the middle, Format SQL follows your rules, and View > Zoom resizes the editor, grid or diagram.
  • Schema browser: tables, columns and types, a quick filter, a canvas with foreign-key lines, a Temporary section for the session's temp tables, PostgreSQL partitions under their parent table, and attached SQLite databases. It stays responsive at 50,000 tables.
  • Join query builder: pick tables and get the join along their foreign keys, with columns, filters and a live SQL preview.
  • Structure editor: add, change and drop columns, indexes and keys, with a preview of the exact SQL that runs, also on the schema canvas (drag a column to add a foreign key), plus an editor for PostgreSQL enums, domains and composite types and MySQL/MariaDB table character set, collation and AUTO_INCREMENT.
  • Copy Objects: copy tables and their rows to another PostgreSQL, MySQL/MariaDB or SQLite connection, with type warnings and an editable preview. A failed or cancelled copy leaves nothing behind on PostgreSQL and SQLite; on MySQL/MariaDB Dblore drops the tables it created.
  • Compare Schemas & Sync: compare two PostgreSQL, MySQL/MariaDB or SQLite schemas, review the exact script, and run it through Safe Mode, with drops unticked by default.
  • Results grid: several result sets as tabs; sort, search, filter, edit values inline (also the cells of auto-updatable PostgreSQL views), add rows from a form, follow foreign keys, inspect cells as JSON, color values by type, pin a result to compare re-runs and freeze leading columns in table tabs. Binary values show as hex, UUID, MessagePack or Protobuf, and cells over 64 KB load only when you open them. Paste rows from the clipboard, see the rows a delete would cascade to, set to NULL or be blocked by before you commit it, see a Reload banner when another tab changed the table, and switch any result between grid and chart.
  • Table Health: find tables without a primary key, foreign keys without an index, and unused or redundant indexes and bloated tables from the server's statistics, then copy the report.
  • Import and export: import CSV, TSV and JSON as new rows or updates matched by key, several files or a folder in one transaction; export to Excel, CSV, JSON, Markdown, PDF, TSV and SQL INSERT.
  • Generate Rows: fill a table with up to 1,000,000 rows of sample data that follow its types, foreign keys and unique keys.
  • SQL dump and restore: dump a PostgreSQL, MySQL/MariaDB or SQLite database to a .sql file, with Structure, Data and Drop per table, and restore it.
  • Safe Mode: confirmation before destructive statements, Commit / Rollback for pending transactions, Touch ID to unlock.
  • Lock: lock a connection, a database file or a whole workspace behind Touch ID, the Mac password or a Lock password. Locked workspaces are encrypted on disk, and locked items relock on sleep, screen lock or idle.
  • Column masking: hide columns by name per connection (Full, Last 4, Email or NULL) in results, copies, exports, AI and MCP. It matches names, so an alias gets past it: it is not access control.
  • Query Insights: your queries grouped by shape, with runs, average, p95 and slowest time, and error rate.
  • AI assistant: write, explain and fix SQL with your own key, Apple Intelligence or a local model (on-device models need the On-device AI plugin). Nothing runs unless you allow read-only queries, and row values are sent only if you turn on Send result rows to AI. It can call tools of outside MCP servers you add, each call only after you press Run once. It can also change Dblore's own settings on request, with Undo.
  • MCP server: let Claude Code or Cursor read the connections you allow, on this Mac only. Off by default. Optional write tools run one change at a time, only after you approve it.
  • Command line and Shortcuts: query the connections you allow from a terminal with dblore, or from the Shortcuts app with Open Connection, Run Query and Add Row.
  • Vault credentials: take a connection's login from a HashiCorp Vault lease on every connect, renewed while connected and revoked on disconnect.
  • Keyboard-first: run cells and queries without leaving the keys, and find any command with Cmd+K.

Databases

  • PostgreSQL: saved connections, passwords in the Keychain, SSL, client certificates, SSH tunnels, read-only mode, and import from DBeaver, TablePlus, DataGrip, .pgpass or a URI.
  • MySQL and MariaDB: TCP or SSH tunnel, TLS and client certificates, staged edits by primary key, foreign-key lookup, CSV import, routine and trigger source, and import from DBeaver, TablePlus, DataGrip or a mysql:// URI.
  • MongoDB: a connection string or form, mongosh commands, a collection screen with a filter bar, schema, indexes and validation, editable document cards, an aggregation builder, index and collection administration, export, import, backup and restore, and edits staged by _id and confirmed in Safe Mode.
  • SQLite: open a file and work with it like a server connection.
  • SQL Server (plugin): TLS or an SSH tunnel, schemas, procedures and functions, data viewer paging and filters, grid edits on tables with a primary key, transactions and Stop.
  • ClickHouse (plugin): HTTPS or HTTP, directly or through an SSH tunnel, databases as schemas, data viewer paging and filters, Stop and Explain as text. Read-only connections are enforced by the server.
  • Presets: CockroachDB, Redshift and YugabyteDB through the PostgreSQL driver, TiDB and SingleStore through the MySQL one, with their default port; the PostgreSQL presets also skip the settings and catalog reads the engine lacks. Redshift and SingleStore are untested.

Plugins

Optional engines and features, installed from Settings > Plugins: a signed, notarized download, checked before every load and removable at any time.

  • DuckDB: open a .duckdb file or an in-memory database, browse its schema and query Parquet or CSV files.
  • SQL Server: connect to SQL Server with TLS (about 2.3 MB). Built on FreeTDS (LGPL-2.1) and OpenSSL (Apache-2.0); Settings > Plugins links their licenses and the exact FreeTDS source.
  • ClickHouse: connect to ClickHouse over HTTPS or HTTP, with no third-party code.
  • On-device AI: run AI models on this Mac with MLX for the AI chat and inline suggestions. Models download separately, each file checked by its SHA-256.

Get started

  1. Download the signed and notarized DMG from the releases page and drag Dblore to Applications.
  2. Connect to a PostgreSQL, MySQL, MariaDB or MongoDB server (or a SQL Server or ClickHouse server once its plugin is installed), or open a SQLite file.
  3. Create a notebook (Cmd+T) and run a cell (Ctrl+Enter).
