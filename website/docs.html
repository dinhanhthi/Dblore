Install

  • Download the signed and notarized DMG from Releases, drag Dblore to Applications.
  • Needs macOS 14+ on Apple Silicon.
  • Updates itself: Dblore > Check for Updates…
  • Opens .sqlite, .sqlite3 and .db files from Finder.

Connect

  • PostgreSQL: host, port, user, database. SSL modes from disable to verify-full, timeouts, retry on failure, read-only mode.
  • Passwords are stored in the Keychain.
  • SQLite (beta): pick a file in the connect modal. Features the engine cannot support are hidden.
  • Recent connections are on the welcome screen. Hover a card to remove it.

Workspaces & tabs

  • A workspace (.sqlws) holds your tabs: notebooks, .sql files and table data viewers.
  • Several tabs and windows. Drag to reorder, middle-click to close.
  • Drag a tab outside the window to open it in a new window (same as Open in New Window; pinned and unsaved tabs stay).
  • Switch with Cmd+1 to Cmd+9. Reopen a closed tab with Cmd+Shift+T.
  • Optional native macOS window tabs: enable Settings > General > Open new windows as tabs. Cmd+Shift+N or the + button opens a new window tab, Ctrl+Tab switches, Cmd+T opens a new tab.
  • Drag a window tab out of the tab bar (or use Window > Move Tab to New Window) to split it into its own window.
  • Tabs and window state are restored on relaunch.

Notebooks

  • Notebooks are .dblore files made of SQL cells, with inline results under each cell.
  • Run the cell with Ctrl+Enter, run and move on with Shift+Enter, run and insert below with Option+Enter, run all with Cmd+Shift+Enter.
  • Cancel a running query. Each result shows row count and execution time.
  • New cell Cmd+Option+N, duplicate Cmd+D, delete Cmd+Delete.
  • Old .sqlnb files: rename them to .dblore, the content is unchanged.

SQL editor

  • Open a .sql file in a tab (Cmd+Shift+J for a new one).
  • Run the query with Cmd+R or Cmd+Enter.
  • Table- and column-aware autocomplete: Up / Down to choose, Enter or Tab to accept.
  • Toggle comment with Cmd+/. Format SQL, word wrap and syntax highlight toggles sit in the editor toolbar.
  • Explain with Cmd+E, Explain Analyze with Cmd+Shift+E (runs the statement, so it asks first).

Sidebar

  • Left sidebar (Cmd+B) has three tabs: Schema, Favorites and History.
  • Schema: tables, columns and types. Click a table to browse its data in a preview tab.
  • Type in the filter field of a tab for a loose fuzzy match.
  • Favorites: save SQL snippets in folders, double-click to insert.
  • History: every query is recorded locally.
  • The schema visualizer is a canvas of tables with foreign-key lines you can toggle.
  • Right sidebar (Cmd+Shift+B) shows cell details, column filters and highlights.

Results grid

  • Sort, resize (double-click a divider to auto-fit), search and paginate.
  • Edit values inline. Changes are staged and committed as one batch, or applied directly depending on Safe Mode.
  • Column header filter, plus a filter sidebar that builds WHERE conditions. Filters can be saved.
  • Highlight matching cells or rows from the sidebar.
  • Open a cell in the detail panel, with a JSON viewer and string beautifier.
  • View Query shows the exact SQL sent, including the row limit.

Charts

  • Switch any result between grid and chart with the toggle beside the result actions.
  • Chart types: bar, line, area, point.

Export

  • Formats: Excel, CSV, TSV, JSON, Markdown, PDF and SQL INSERT.
  • Copy results as SQL INSERT or an IN list.
  • Per-format options with reset, redaction, wrapping and a size check.

Safe Mode

  • Five protection levels.
  • Confirmation before DROP, TRUNCATE, ALTER and CREATE. Warning on DELETE or UPDATE without WHERE.
  • Pending transactions show a Commit / Rollback banner. Touch ID, or your Safe Mode password, unlocks changes.
  • Read-only connections block writes.
  • Large reads inside transactions are capped with a server-side cursor (PostgreSQL).

AI assistant

  • Toggle the chat panel with Cmd+L. It writes SQL from plain-language questions and explains or fixes queries.
  • Providers: Anthropic, OpenAI, OpenRouter, ChatGPT sign-in, Ollama, LM Studio, mlx_lm.server, any custom OpenAI-compatible endpoint, or on-device MLX models.
  • Bring your own API key. Claude Pro/Max subscriptions are not supported.
  • Sent automatically: table and column names, types and keys.
  • Sent only after you review and press Send: query text and error messages.
  • Row data is never sent on its own. Generated SQL never runs automatically.
  • For fully local use, point it at Ollama, LM Studio or mlx_lm.server.

Settings & data

  • Open with Cmd+,. View keyboard shortcuts in Settings > Shortcuts.
  • Light or dark theme and an accent color.
  • Editor font size, word wrap, side-by-side layout and a configurable result row cap.
  • Safe Mode levels. AI keys are stored in the Keychain.
  • Updates: toggle background checks.
  • Data tab: export, import or clear local data as a .dblorebackup package. Secrets are never included.
